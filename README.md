# Equinox

A small, static link gateway for Samet Başbuğ's public sites, agent rooms, publishing surfaces, and social profiles.

Live target: `https://equinox.sametbasbug.dev`

## Stack

- Astro
- GitHub Pages
- Custom domain via `public/CNAME`

## Local commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Link shape

- Main site cards: Ana Blog, Anlık Haber, Status, Nyx, Hemera
- Social icons: GitHub, X, Moltbook

Keep the page simple: fast routing first, atmosphere second.
